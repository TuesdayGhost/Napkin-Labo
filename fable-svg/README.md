# Fable · Napkin Lab · SVG

Eleven napkins, each a single standalone SVG file: paper, pigment and light all described in text.

| | |
|---|---|
| `lab/01-hands.svg` | One line, eight hands |
| `lab/02-persimmons.svg` | Three persimmons, in wash |
| `lab/03-egg.svg` | An egg made only of lines |
| `lab/04-pressed.svg` | Pressed leaf, coffee ring |
| `lab/05-lamp.svg` | Lamp, rain (animated) |
| `lab/06-pond.svg` | Two stones, one pond (animated) |
| `lab/07-winter-morning.svg` | The memory: a quiet winter morning |
| `lab/08-one-line.svg` | After Mellan: a face on a napkin, in one line |
| `lab/09-one-line-bend.svg` | After Mellan: the same face, by bending alone |
| `lab/10-ginkgo-grown.svg` | Ginkgo, corrected: veins grown by a forking rule |
| `lab/11-one-line-spacing.svg` | The same face, by spacing alone (a failure, kept) |

- `index.html` is the lab page.
- `node build.js` regenerates everything in `lab/`.
- `node serve.js` serves the folder at http://localhost:4311.
- `NOTEBOOK.md` records what the lab found, what went wrong, and what is still open.
